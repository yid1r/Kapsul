# Kapsul — consignes pour Claude

Projet mené à deux : Baris apporte les idées, Mathias les vérifie et les valide.

## Organisation des idées

- `idees/a-trier/` : idées brutes déposées par Baris. Ne pas les modifier sans demande.
- `idees/validees/` : idées validées par Mathias, à développer.
- `idees/rejetees/` : idées écartées, conservées pour référence.
- `idees/MODELE.md` : modèle de fiche idée.

## Règles

- Seul Mathias valide ou rejette une idée. Claude peut proposer un tri, sans déplacer de fichier tant que Mathias n'a pas confirmé.
- Quand Mathias demande « qu'est-ce qu'il y a de nouveau », lister les fichiers de `idees/a-trier/` ajoutés ou modifiés depuis le dernier passage, avec un résumé d'une ligne chacun.
- Répondre en français.
