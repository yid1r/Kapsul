# Espace idées

C'est ici qu'on dépose toutes les idées pour Kapsul.

## Comment ça marche

| Dossier | Qui | Quoi |
|---|---|---|
| `a-trier/` | Baris (et tout le monde) | Les nouvelles idées, brutes |
| `validees/` | Mathias | Les idées retenues, prêtes à être développées |
| `rejetees/` | Mathias | Les idées écartées (on les garde, elles peuvent resservir) |

## Ajouter une idée (Baris)

Pas besoin de logiciel, tout se fait sur le site GitHub :

1. Ouvre le dossier `idees/a-trier/`.
2. Clique sur **Add file → Create new file**.
3. Nomme le fichier avec quelques mots, sans espace ni accent, et termine par `.md`. Exemple : `episode-ia-et-emploi.md`
4. Copie-colle le contenu de `MODELE.md` et remplis-le. Si t'as la flemme, écris juste ton idée en vrac, c'est OK.
5. En bas, clique sur **Commit changes**.

Depuis le téléphone, l'appli GitHub permet aussi de lire les fichiers, mais pour en créer c'est plus simple sur le navigateur.

## Valider une idée (Mathias)

- Retenue : déplacer le fichier dans `validees/`.
- Écartée : le déplacer dans `rejetees/` et ajouter une ligne qui dit pourquoi.
- À retravailler : ajouter une section « Retour » dans le fichier et le laisser dans `a-trier/`.

Claude Code peut faire le tri et développer les idées validées sur demande.
