# Kapsul

Launcher Android pour consoles portables : pensé pour la manette, personnalisable de A à Z, compatible double écran.

- **[Concept et plan de construction](docs/CONCEPT.md)** : le modèle, les améliorations argumentées, l'architecture et la feuille de route.
- **[Prototype interactif](prototype/index.html)** : ouvrir le fichier dans un navigateur. Flèches pour naviguer, Entrée pour valider, Échap pour revenir, O pour les options. Une manette branchée fonctionne aussi.
